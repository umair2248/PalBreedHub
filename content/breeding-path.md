## How the breeding path finder works

Add the Pals you already own, then pick the Pal you want. The path finder checks every pair you can breed right now (generation 1), then every pair you could breed with those new Pals too (generation 2), and so on, until it reaches your target. The first generation that contains the target is the shortest possible path, so you never breed more generations than needed.

When several pairs give the same Pal, it picks the one that needs the fewest breeding steps, so the whole breeding tree stays small. Your owned Pals are saved in this browser, so you can come back later and only add the new ones you catch.

## Tips for using the breeding tree

- Add every Pal you have, even weak early ones. More starting Pals usually means a shorter path.
- Every step needs a male and a female parent. If a step shows ♂ or ♀, that parent must have that gender.
- Some Pals, like [Grizzbolt](/pals/grizzbolt/) or [Shaolong](/pals/shaolong/), can only be bred from two of themselves. The path finder can't reach them unless you already own one, so catch a pair first.
- Want to see every possible pair instead? Use the [Breeding Chart](/breeding-chart/) or the [breeding calculator](/).

## FAQ

### What is a breeding tree in Palworld?

A breeding tree is the chain of breeding steps from Pals you have to a Pal you want, often over several generations. Each step's child becomes a parent in the next step.

### Is the shortest path always the easiest one?

It is the one with the fewest generations. A path with one more generation can sometimes use more common Pals, so check each Pal's page if a parent is hard to get.

### Are my Pals saved?

Yes, in your browser on this device only. Nothing is sent to our server.
